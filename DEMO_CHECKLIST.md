# Demo Recording and Screenshot Checklist

## Suggested 2–3 minute walkthrough
1. Opening: show the deployed app and identify it as the Seconize Task Manager PoC.
2. Dashboard: show project/task counts and progress.
3. Project management: create a disposable project, edit it, and show the saved result.
4. Task management: create a task with title, description, assignee, priority, status, and deadline; edit it.
5. Kanban: move a task between statuses and refresh to verify persistence.
6. Collaboration: show comments, subtasks, and activity history only if implemented and working.
7. AI: try one or two prompts, then verify answers use real application data:
   - “Show my overdue tasks.”
   - “Break down the login module into implementation tasks.”
   - “Create a high-priority login validation task assigned to Arun with a deadline of 28 October 2026.”
8. Closing: show the GitHub repository and technology stack.

## Recording tips
- Use disposable demo data; avoid deleting real work.
- Hide API keys, passwords, database credentials, and private information.
- Refresh after important changes to demonstrate persistence.
- Close unrelated tabs and notifications; keep browser zoom around 90–100%.
- Prefer one continuous recording under 3 minutes.
- If a feature fails, omit it rather than showing misleading evidence.
